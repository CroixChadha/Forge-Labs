# Forge-Labs
A Claude powered software company simulation for learning software engineering and AI engineering through missions, projects, reviews, and an Obsidian-based knowledge system.


# Better description
Forge AI Labs is a GPT-powered simulation of a real software company where the learner operates as a junior engineer.

The system uses multiple Markdown files stored locally in an Obsidian vault to track missions, skills, engineering decisions, bugs, reviews, progress, and learning outcomes.

It is designed to teach practical software engineering and AI engineering through realistic workplace simulations, project-based learning, code reviews, debugging exercises, architecture decisions, and progressive AI-assisted workflows.

Feel free to adapt or use the system if it supports your own learning journey.

All html files/missions are in this repo. feel free to take a look at them. All assignments are Claude generated and graded by Claude under a different project.
